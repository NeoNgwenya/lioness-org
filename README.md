# Lioness.Org

A Next.js App Router site about menstrual dignity and Lioness.Org’s work in Southern Africa.

## Run locally

Use Node.js 20.9 or newer.

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Build

```sh
npm run typecheck
npm run build
```

The production build exports to `out/`, ready for a static host.

## Content and contact

- Visit `app/page.tsx` to update the site copy, dated project details and contact address. The project figures and logo come from the supplied 2021 Lioness.Org learning report.
- The hero uses an AI-generated illustration. Replace `public/images/dignity-hero.webp` with an approved project photo and update its alt text and caption when available.
- Sponsorship and volunteering links open a pre-addressed email. Confirm that `zanele@lioness.org` can receive mail before launch.
